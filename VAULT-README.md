# AI Agent Vault — Lite (free)
A starter Obsidian vault for working with AI agents: universal AGENTS.md + CLAUDE.md, a bot-memory layout, daily & weekly templates, and 3 prompts.

**Full version ($19)** adds: 12-prompt library, 4 agent runbooks (inbox, daily, weekly, research), complete bot memory (facts, decisions, glossary, active context), 10 templates, Dataview dashboard, generic system prompt for ChatGPT/Grok/Gemini/local models, example notes, and the 25-page Setup Guide (PDF) with Claude Code, Claude Desktop (MCP) and ChatGPT/Grok walkthroughs.

Open this folder in Obsidian → Settings → enable Templates and Daily notes. Example data is fictional.
